# Pulse

好看的 Mac **内存诊断器**（一期 MVP）。外表像活动监视器，任务按诊断走：30 秒内找到吃内存的进程并安全退出。

## 一期范围

- 单页：用量大数 → 分类条 → 压力 → 按内存排序的进程表 → 侧栏曲线 + 退出 / 强制退出
- 技术：SwiftUI 原生、公证直装（Hardened Runtime）
- Bundle 暂名：`Pulse`（可改）

## 明确不做（一期）

- 磁盘 / 网络深页、菜单栏常驻
- 自动判泄漏、增长斜率
- Electron / 多平台
- App Store 沙盒、TCC 全盘、内核扩展
- 侧栏分享、耗电 / GPU / 磁盘 / 网络小格
