# ADR-0009：GPU 占比读 AGX 用户客户端已公布的累计时间

状态：已采纳（#204）。这是 [ADR-0004](0004-gpu-accelerator-stats.md) 的补充，不改整机 GPU 使用率和占用内存的来源，也不放开对 `IOServiceOpen`、Metal 计数器和 `powermetrics` 的禁止。不改变 [ADR-0008](0008-gpu-history-keeps-recording.md) 的整机使用率曲线和 `gpu-core-count`。

## 背景

GPU 页已经有整机使用率。整机百分比看不出是哪一个进程在用 GPU。AGX 把每个用户客户端的累计 GPU 时间写在注册表里，只读属性就能拿到，不必打开用户客户端。Intel 加速器没有这组 `AppUsage` 记录。

这是 GPU 使用率旁边的另一个指标。GPU 使用率仍是整机 0–100 的设备百分比。GPU 占比是最近一个采样间隔里，单个进程的 GPU 时间占墙钟时间的比例。

## 决定

- 只读 `AGXDeviceUserClient` 已经公布的属性。pid 来自 `IOUserClientCreator`，累计 GPU 时间来自 `AppUsage` 里的 `accumulatedGPUTime`（纳秒）。同一个 pid 的多个客户端先相加。不调用 `IOServiceOpen`，不打开用户客户端。
- 两帧相减，再除以这两帧之间的墙钟时间，显示一位小数。重叠的 GPU 工作可以超过 100%，保留，不截断。真实增量为 0 是 `0.0%`。
- 计数回绕、上一帧的某个客户端消失、或这一项读不出，这一行是「—」，不是 0。新出现的客户端只当作基线，不把累计时间算进这一拍。第一拍还没有上一帧，也是「—」。
- 没有 AGX 客户端时，整张卡是缺失（「读不到 GPU 占比」），不是一排 0。不改用 Intel 上直接挂着的累计时间。
- Pulse 自己的行留在榜上，名称写成「Pulse」。不用散热建议那条丢掉自身 pid 的过滤。
- 只在 GPU 页可见时取前 5 名：有数字的占比从高到低，相同则 pid 较小的在前。其它页不更新这张卡，也不把离开期间的样本当成基线。整机使用率仍按 ADR-0008 在每一页记录。
- 每行「退出」走和散热建议相同的 `ProcessActions.terminate`。不进菜单栏、快照、本机卡片或进程表。GPU 页仍没有完整进程表、名称过滤或详情侧栏。

## 后果

- Apple Silicon 上，GPU 页在读数和曲线下方列出最多 5 个进程的 GPU 占比。
- Intel 或读不到客户端的机器只看到一张缺失卡。
- 不要把 GPU 占比写回整机使用率，也不要为了这一项去打开用户客户端。
