# ADR-0005：公网 IP 只在用户点击后查询

状态：已采纳（#166）。不改变 [ADR-0001](0001-process-memory-footprint.md) 的进程内存占用，不改变 [ADR-0002](0002-process-energy-wakeups.md) 的能耗和唤醒，不改变 [ADR-0003](0003-thermal-state-api.md) 的热状态来源，不改变 [ADR-0004](0004-gpu-accelerator-stats.md) 的 GPU 读数。

## 背景

公网 IP 要向外面的服务问一次「你看到的地址是什么」。Pulse 到这次之前没有出站请求。启动时自动去问，或在后台隔一会儿再问，都会在用户没有动作时把这次访问发出去。

地址还会随网络变。自动刷新没有一个稳妥的间隔，也解释不了为什么应用自己要往外连。

## 决定

- 这是 Pulse 的第一次出站请求。只有用户点「查询公网 IP」之后才发。
- 启动不请求，采样不请求，没有轮询，也没有自动刷新。下次启动回到未查询。
- 请求用一次性的 ephemeral 会话，不留缓存，也不把 cookie 写到磁盘。
- 查到的地址只留在内存里。不写入磁盘，也不放进菜单栏。默认不放进快照。用户在这一份快照里关掉「隐去 IP」时，才把已经留在内存里的地址写进预览和文件；保存不发起新的查询（#193）。

## 后果

- 不点按钮，就没有这次出站请求。
- 失败时不再显示上一次的地址。用户要再看，就再点一次。
- 不要把这次查询接进采样循环或菜单栏。保存快照也不发起这次查询。
