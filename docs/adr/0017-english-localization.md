# ADR-0017：英文本地化用 String Catalog，英文只是译文

状态：已采纳（#199）。#182 把这项标成 ready-for-agent，授权在本条定案。不改变 [ADR-0001](0001-process-memory-footprint.md) 的内存占用，不改变 [ADR-0002](0002-process-energy-wakeups.md) 到 [ADR-0012](0012-energy-model-power-frequency.md) 的读数，也不改变 [ADR-0005](0005-manual-public-ip-request.md)。英文界面不新增出站请求。

## 背景

界面上的简体中文写在源代码里。工程开发语言已经是 `zh-Hans`，已知区域里已经有 `en`。还没有 String Catalog。

英文用户需要整份界面。英文必须沿用现在的冷静读数，不能另写一套催促或吓人的文案。调研第 4 节第 13 项把英文本地化和 Sparkle、收费放在一起。第 8 节要另写 ADR 的是联网，不是翻译。#182 对这项的约束只有两条：用 String Catalog，并且先写英文风格指南。

## 决定

- 用一份 String Catalog（`Localizable.xcstrings`）。开发语言保持简体中文。英文用已有的 `en`，不加地区变体。
- 英文是译文，不是第二套手写界面。键用简体中文原文。不把开发语言改成英文，也不为了好译而改中文。
- 风格指南在任何迁移之前落地：[英文风格指南](../i18n/english-style.md)。声音是冷静、具体、短。写出读数。不催用户。
- 缺数仍是「—」。不写成 0，不写成 N/A，也不写成 unknown。真实的 0 仍是 0。
- 英文不用这些词：leak、danger、dangerous、urgent、critical、junk、bloat、suspicious、infected、kill。Force Quit 只许作为「强制退出」这个动作的名字。告警规则译成 Notice rules，不译成 Alerts。
- 术语对照以 `GLOSSARY.md` 为准，写在风格指南里。不使用该表写明要避开的说法。
- `WiringSourceTests` 继续锁定简体中文。某一张 ticket 把字符串收进目录时，同一张 ticket 把对应测试改成锁定 zh-Hans 的值。测试不锁定英文。
- 一次只迁一块界面。

## 后果

- 系统语言是英文时，已经迁过的界面显示英文。还没迁的仍显示中文原文。
- 简体中文用户看到的句子不变。读数口径不变。
- 不增加出站请求，不改权限、沙盒、签名或公证。
- 提议不得当作 `docs/TECH.md` 的现行行为。本条是已采纳，不是提议。后续 ticket 落地之前，也不要把英文界面写进 `docs/TECH.md`。

## 不考虑

- 不维持一套和中文平行的手写英文，也不改用多个 `.strings` 当主目录。
- 不在测试里锁定英文，也不靠测试判断译文好不好。
- 不一次迁完全部界面。
- 不把缺数译成一个英文词。
- 不在本条决定 Sparkle、收费或 Mac App Store。那些不由本条补充 ADR-0005。
- 不改 `GLOSSARY.md`。

## 后续实现 ticket

### 1. 加入目录，只迁设置

- 阻塞：无
- 交付：设置在英文系统语言下是英文，简体中文下仍是原来的句子。其它界面仍是中文。
- 测试接缝：WiringSourceTests。锁定设置的 zh-Hans。抓住中文被改掉，或被英文换进源文。放掉译文是否符合风格指南，也放掉设置以外的界面。

### 2. 菜单栏、压力和通知

- 阻塞：第 1 张（同一份目录）
- 交付：菜单栏、压力两档和告警规则的句子有英文。菜单栏英文里没有 Force Quit，也没有禁用词。缺数仍是「—」。
- 测试接缝：WiringSourceTests。锁定这些表面上的简体中文。抓住「正常 / 偏高」「余量充足 / 余量紧张」和通知文案还在，以及菜单栏中文仍不吓人。放掉英文用词，也放掉切换语言后的实机显示。

### 3. 各资源页

- 阻塞：第 1 张
- 交付：内存、CPU、能耗、磁盘、网络、本机、GPU 各页上用户看得到的标题和句子有英文。缺数仍是「—」，真实 0 仍是 0。
- 测试接缝：WiringSourceTests。锁定这些页的 zh-Hans。抓住标题和缺数记号没有换成英文或 0。放掉译文有没有用术语表，也放掉采样对不对。

### 4. 症状诊断、快照预览和进程说明

- 阻塞：第 1 张
- 交付：症状诊断、用户看得到的快照预览，以及界面上的进程说明句子有英文。判断仍是原来的三档，不另写结论。
- 测试接缝：WiringSourceTests。锁定这三处用户看得到的简体中文。抓住句子仍是 zh-Hans，没有被英文替换。放掉译文是否达意，也放掉快照里不展示的字段。预览句子若由 SnapshotExport 生成，同一张 ticket 用 SnapshotExport 锁定预览中的中文，不为英文加断言。
