# ADR-0020：GPU 功耗只用 `GPU Energy` 通道

状态：已采纳（#220）。取代 [ADR-0012](0012-energy-model-power-frequency.md) 里「GPU 功耗把通道名含 `GPU` 的有限瓦特相加」这一条。ADR-0012 的其它规则不变：只在 GPU 页被选中时读，第一拍只做基线，单位按通道自己的 `mJ` 或 `nJ`，CPU、ANE、DRAM 的认法和 GPU 频率都不变。

## 背景

Energy Model 里和 GPU 有关的通道不止一条。MacBookPro18,3（M1 Pro）、macOS 26.6.2 上是 `GPU0`（mJ）、`GPU SRAM0`（mJ）和 `GPU Energy`（nJ）。三次 1 秒测量里，`GPU Energy` 约等于 `GPU0 + GPU SRAM0`，例如 0.285 W、0.011 W 和 0.303 W。按 ADR-0012 把名字带 `GPU` 的全部相加，得到约 0.6 W，是实际的两倍左右，和活动监视器等工具不在同一量级。

## 决定

- 这一拍有名字正好是 `GPU Energy` 的通道时，GPU 功耗只用这一条，不再加其它名字带 `GPU` 的通道。名字要完全相同，区分大小写。
- 没有 `GPU Energy` 时，仍把名字含 `GPU` 的通道的有限瓦特相加。
- `GPU Energy` 在但这一拍读不成瓦特（单位不认识、差为负、或不是有限数）时，GPU 功耗是「—」，不退回去把其它 GPU 通道相加。
- 一个都对不上是「—」。真实 0 仍是 `0.0 W`。不把缺数写成 0。
- 文案、读取时机、页面位置不变，仍不进菜单栏、快照、进程表或本机历史。

## 后果

- 有 `GPU Energy` 的机器上，GPU 功耗大约是原来的一半，和活动监视器同一量级。
- 只有分项通道的芯片仍有读数，口径和以前一样。
- 以后若某代芯片的总通道换了名字，会退回分项相加，不会重复计算；若总通道和分项同时存在但换了名字，要再改本条。

## 不考虑

- 同时有总通道和分项时取较大者或平均：两者本来就是同一份能量。
- `GPU Energy` 读不到时退回分项相加：同一拍里口径会来回跳。
- 按名字大小写不敏感匹配 `GPU Energy`：测到的名字就是这一种写法。
