# ADR-0019：买断许可证离线校验，现有功能保持免费

状态：提议（#214）。提议不是现行行为，不要写进 `docs/TECH.md`。不补充 [ADR-0005](0005-manual-public-ip-request.md)：许可证在本机校验，不增加出站请求。不改写 [ADR-0018](0018-sparkle-updates.md)：更新仍是询问后才有的另一次出站，许可证检查不捎带在上面。不改变 [ADR-0013](0013-disk-space-analysis.md)、[ADR-0014](0014-desktop-widget.md)、[ADR-0015](0015-on-device-explanation.md)、[ADR-0016](0016-command-line.md) 里各功能自己的规则，只决定没有有效许可证时哪些先不开。不改变 [ADR-0017](0017-english-localization.md)：英文不是付费项。不改变 [ADR-0001](0001-process-memory-footprint.md) 的内存占用，也不改变已采纳的能耗、热状态、GPU、历史和功耗频率。主应用保持非沙盒。

## 背景

今天的 Pulse 没有许可证，也没有商店。内存、CPU、网络、磁盘速率、GPU、能耗、本机页、历史、告警规则、症状诊断、快照和菜单栏都在用。进程说明、可安全退出、退出、强制退出、暂停、降低优先级、启动项，以及点击之后的公网 IP，同样已经在。#182 要求这些现有功能留在免费里。升级不能把它们拿掉。

还没做、而且以后要持续花工夫的，是另一批：把磁盘空间分析里的目录移进废纸篓、桌面小组件、`pulse` 命令行，以及规则原文之上的模型措辞。调研把授权校验和 Sparkle 都写成会联网，所以本条被 #200 挡住。ADR-0018 已经把更新收成询问后的检查，并写明更新请求不捎带许可证；授权若要联网，先改授权自己的决定，再补充 ADR-0005。

本条把授权留在本机。不联网，就不补充 ADR-0005。订阅要反复去问有没有过期，和这条不合。Mac App Store 的沙盒做不到强制退出，也读不到其它进程。Setapp 的 SDK 在线核对订阅，是另一次决定。

## 决定

- 今天主线上已有的功能全部免费，升级不删除。包括内存、CPU、网络、磁盘速率、GPU、能耗、本机页、历史、告警规则、症状诊断、快照、菜单栏，以及进程说明、可安全退出、退出、强制退出、暂停、降低优先级、启动项和点击后的公网 IP。缺数仍是「—」，不是 0。没有许可证也不改这些读数，不把缺数填成 0。
- Pro 只有四件，都还没做：把磁盘空间各类移进废纸篓；桌面小组件；`pulse` 命令行；规则原文之上的模型措辞。规则原文免费。磁盘空间的查看、手动扫描和大小不收费，缺数仍按 ADR-0013 写成「—」。英文界面和 Sparkle 更新不收费。
- 一次购买，长期有效。不是订阅。不做要反复联网的到期或续费。本条不写售价。
- 许可证是一份文件，只用 EdDSA 在本机校验。公钥在 App 里。私钥不进仓库，也不进公证脚本的输出。这把钥匙不是 Sparkle 的 `SUPublicEDKey`，两把不混用。只有用这把公钥验得过的才是有效。其它是无效。没有文件是缺失。不激活，不登记这台 Mac，也不为换机再问服务器。
- 校验不发起出站请求，所以不补充 ADR-0005。启动不为此联网，采样不为此联网。公网 IP 仍只在点击「查询公网 IP」之后才查，那一次也不捎带许可证。将来若要联网校验，先改本 ADR，再补充 ADR-0005，然后才能做。
- Sparkle 仍按 ADR-0018：默认不检查；还没问过或拒绝，就不连接；允许之后才交给 Sparkle。更新请求不携带、不核验许可证。校验许可证也不去拉 appcast，不创建更新器。更新不看有没有买过。
- 没有有效许可证时，四件 Pro 的入口标明未解锁。未解锁不是缺数，不写成「—」，也不写成 0。免费页照常。完全磁盘访问和有没有许可证不是一件事：没授权时大小仍是「—」，不是因为没买。
- 废纸篓：没有有效许可证就不移。不改成永久删除，不调用 `rm`，不调用 `purge`。有许可证时仍只有废纸篓。Time Machine 本地快照，以及不能整目录进废纸篓的 Docker 镜像，仍然不提供删除。扫描和大小不看许可证。
- 小组件：没有有效许可证时，主应用不发布快照，也不把已经发布的快照留在小组件还能读到的地方。不写 0，不写「正常」，不编造进程来补满三行。这不是采样失败，不用「失败不覆盖」把 Pro 读数留住。有许可证时，采样失败仍不覆盖上一份成功读数，也不编造。小组件仍不自己采样。解锁之后，压力仍只有「正常」和「偏高」，缺数仍是「—」，最多 3 行，下一次刷新不早于 15 分钟，沙盒仍只在扩展上。这些都按 ADR-0014。
- 命令行：包里仍可以有这个可执行文件。没有有效许可证时，它自己在本机看出缺失或无效，然后拒绝并退出。不附着到正在运行的应用，不采样，不打印全 0 或一份看起来像采样的 JSON，不打开端口，也不联网查许可证。有许可证之后仍是一次性命令。口径、缺失用 `null`、快照默认隐去，以及拒绝常驻端口，都按 ADR-0016。
- 模型措辞：没有有效许可证时显示规则原文。进程说明和症状卡不消失，诊断也不改。有许可证之后仍只复述本机已经有的说明和依据；越出证据、模型不可用或调用失败，仍退回规则原文。不为措辞联网，也不附带模型权重。
- Setapp 先不做。要做就得先改本 ADR，并补充 ADR-0005，因为那个 SDK 会在线核对订阅。Mac App Store 不做。主应用保持非沙盒。分发仍是 Developer ID，经 `scripts/notarize.sh` 公证，不改成 Mac App Store 证书。
- 许可证文件不放进快照，不放进菜单栏，不放进历史。

## 后果

- 不购买时，现有各页和现在的动作与今天一样。没有许可证不会把读数变成 0。
- 购买不增加出站。不点「查询公网 IP」，就仍然没有那一次请求。没同意更新检查，就仍然没有更新连接。这两次出站都不捎带许可证。
- Pro 未解锁时，入口标明未解锁。磁盘空间仍可按 ADR-0013 扫描；移进废纸篓不行。症状和进程说明仍是规则原文。
- 本条在被采纳之前只是提议。不要写进 `docs/TECH.md`。本条不改 `RELEASE.md`，也不改公证脚本。

## 不考虑

- 订阅，以及试用、到期、续费这些要反复联网的核对。
- 应用内向商店或许可证服务器结账、激活，或查询是否已购买。
- 把许可证检查挂到 Sparkle、公网 IP 或采样上。用更新私钥签发许可证。
- 缺许可证时把免费读数改成 0 或「—」，或用「—」表示未解锁。
- 把磁盘速率页、磁盘空间的扫描和大小、规则原文、英文或 Sparkle 收进 Pro。
- 有许可证之后放宽 ADR-0013 的删除，放宽 ADR-0014 的刷新和沙盒，让模型改写诊断，或让命令行常驻、开端口。
- Mac App Store，以及为了上架给主应用开沙盒。现在接入 Setapp。
- 无障碍基线、首次启动引导和售价数字。要联网才能防共享时，不在本条里悄悄做。
