# ADR-0008：GPU 使用率曲线在每一页持续记录

状态：已采纳（#187）。不改变 [ADR-0001](0001-process-memory-footprint.md) 的进程内存占用，不改变 [ADR-0002](0002-process-energy-wakeups.md) 的能耗和唤醒，不改变 [ADR-0003](0003-thermal-state-api.md) 的热状态来源，不改变 [ADR-0004](0004-gpu-accelerator-stats.md) 的 GPU 读数来源和对 `IOServiceOpen` 的禁止，不改变 [ADR-0005](0005-manual-public-ip-request.md) 的公网 IP 查询，不改变 [ADR-0006](0006-location-for-wifi-name.md) 的定位权限，不改变 [ADR-0007](0007-chip-temperature.md) 的芯片温度。

## 背景

GPU 页原先只在这一页被选中时读取，离开即清空曲线。切走再回来，曲线要从头采。整机使用率并不依赖用户正看着这一页。核心数是加速器注册表上已经公布的 `gpu-core-count`，不是另一路使用率。

## 决定

- 整机 GPU 使用率跟着现有主采样拍记录，前台约 1.5 秒，后台约 3 秒，不另开计时器。每一页都读。曲线最多 90 点，只在应用重启后清空，不落盘。
- 使用率缺失不记成 0。这一拍没有读 GPU 时不改已经发布的页。离开不发布这一帧，也不清空。再次进入时曲线已经在。
- 芯片温度仍只在本机页读取。
- GPU 页在注册表有正整数 `gpu-core-count` 时显示「N 核 GPU」。缺失、0、负数、小数或布尔值都不显示这一行。多台加速器取输入顺序的第一个正整数，不相加。成功帧换成这一帧的数；这一帧没有则隐藏，不留上一帧。失败、采样中和离开不改已经显示的核心数。不放进本机页、菜单栏、快照或进程表。
- 仍不调用 `IOServiceOpen`，不读 Metal 计数器。按进程的 GPU 占比不在这一次决定里，见 [ADR-0009](0009-gpu-process-share.md)。

## 后果

- 进入 GPU 页就能看到离开之前已经记下的曲线。
- 没有这个注册表键的机器不显示核心数。使用率和占用内存照旧。
- 不要把曲线改回离开即清空，也不要为 GPU 再加一只计时器。
