# ADR-0013：磁盘空间分析只在手动扫描时申请完全磁盘访问

状态：提议（#195）。提议不是当前行为，不要写进 `docs/TECH.md`。不改变磁盘页的读取 / 写入：那一页仍然不申请完全磁盘访问。不改变 [ADR-0003](0003-thermal-state-api.md) 和 [ADR-0007](0007-chip-temperature.md) 对 `IOServiceOpen` 与 SMC 的禁止，因此不做 SMART。不改变 [ADR-0005](0005-manual-public-ip-request.md)：这次扫描不出站。不改变 [ADR-0001](0001-process-memory-footprint.md) 的内存占用，不改变 [ADR-0002](0002-process-energy-wakeups.md) 的能耗和唤醒，不改变 [ADR-0004](0004-gpu-accelerator-stats.md) 的 GPU 读数，不改变 [ADR-0006](0006-location-for-wifi-name.md) 的定位权限。

## 背景

磁盘页今天只有读取和写入速率。速率来自块设备注册表属性，不打开用户客户端，也不申请完全磁盘访问。本机页另有磁盘剩余。「磁盘满」只用剩余空间，可清除空间写读不到。这些都不是某一类目录占了多少。

DerivedData、模拟器、Docker 镜像、npm 缓存、Gradle 缓存和 Time Machine 本地快照要去读目录。有的位置受保护。完全磁盘访问是系统设置里的隐私开关：用户自己打开，应用内没有像定位那样的系统提示。主应用保持非沙盒，强制退出和读取其它进程依赖这一点。这个开关不写进 entitlements，也不为此把应用放进沙盒。

启动时去申请，或在采样、菜单栏里提起，都是用户还没看这一视图就打扰。跟着采样拍扫目录，读写会很重。把读不到写成 0，会把没授权假装成目录是空的。永久删除、`rm` 和 `purge` 都收不回来。`purge` 还会清掉文件缓存。SMART 要打开磁盘的用户客户端，和禁止的 `IOServiceOpen` 是同一件事。

## 决定

- 磁盘空间分析是单独的视图。不放进磁盘速率页，不放进采样，不放进菜单栏，不放进快照，也不写入历史。速率页仍然不申请完全磁盘访问，也不出现这次授权的说明。
- 不新增 entitlement，不打开沙盒。定位那一条不动。
- 只有用户打开这一视图，并且选择扫描之后，才引导完全磁盘访问。用系统设置 URL 打开「隐私与安全性」里的完全磁盘访问：`x-apple.systempreferences:com.apple.preference.security?Privacy_AllFiles`。URL 只打开这一页，不代替用户打开开关。启动不打开，采样不打开，菜单栏不打开。打不开这一页时，大小仍是「—」，不另找授权办法。系统以后换了 URL，改代码，不新写 ADR。
- 没有授权时不开始统计。每一类都是「—」，不编一个大小。不轮询授权有没有变。用户打开开关之后，要再点一次扫描。
- 还没扫描，和没有授权，数字都是「—」。可以用一句平静的说明区分这两种情况。说明本身不编大小。
- 扫描只在这次手动动作里跑一遍，然后停。不放进 `MemorySampler`，不另开定时器，也不轮询。再扫要再点。下次启动回到未扫描。
- 只统计这六类：DerivedData、模拟器、Docker 镜像、npm 缓存、Gradle 缓存、Time Machine 本地快照。不扫整盘。已授权但某一类读不到，这一类是「—」，其它类照常。已授权而且这一类确实是 0 字节，仍显示 0，不改成「—」。目录不存在、并且能确定它不存在，算 0。分不清是没有还是读失败，算「—」。
- DerivedData、模拟器、npm 缓存和 Gradle 缓存，是当前用户主目录下这四个固定目录的字节合计：`~/Library/Developer/Xcode/DerivedData`、`~/Library/Developer/CoreSimulator`、`~/.npm`、`~/.gradle/caches`。不跟随指向这些根以外的符号链接。能证明不存在的目录是 0。读不到，或分不清，是「—」。
- Docker 镜像不是那份虚拟机磁盘文件，也不是目录遍历。一次手动扫描可以向已经在跑的 Docker 引擎问一次，只读，要镜像字节。不启动引擎。不传删除子命令。引擎没在跑，或文本给不出字节数，这一类是「—」。
- Time Machine 本地快照不是目录遍历。一次手动扫描可以跑一个只读的系统工具，读它已经报出的可清除字节。不跑删除快照的子命令。没有字节数就是「—」。不估算。
- 新的一次扫描替换上一份。这一次某一类读不到，不用上一份的大小填上。
- 结果只留在内存里。不写入磁盘。
- 删除只有一种：把这一类对应的目录移进废纸篓。不永久删除，不调用 `rm`，不调用 `purge`。移不进废纸篓的不提供删除。Time Machine 本地快照只统计；会永久删掉快照的命令不做。不能整目录进废纸篓的 Docker 镜像也不提供删除，避免改走守护进程的永久删除。大小仍可显示；显示不了是「—」。
- 不挡住应用的其余部分。没授权、没扫描时，其它页和采样照常。
- 文案保持冷静。陈述这一类的名字和大小。可以写「完全磁盘访问」和「打开系统设置」，因为那是开关的名字。不写「磁盘将满」「被占满」「磁盘几乎满了」「垃圾」「立即清理」「一键释放」「泄漏」「危险」。

## 后果

- 不点扫描，就没有这次授权引导，也没有目录统计。
- 速率页、本机页的磁盘剩余，以及「磁盘满」卡，都保持现在的行为。可清除空间仍写读不到，不用这次扫描填上。
- 没授权的机器上，这一视图的六类都是「—」。其余功能不受影响。
- 提议被采纳之前，`docs/TECH.md` 不把这些句子当成当前行为。

## 不考虑

- SMART，以及任何要 `IOServiceOpen` 的磁盘用户客户端。风扇转速和风扇控制仍不做。
- 整盘占用图、大文件排行、自动清理、后台重复扫描。

## 后续实现 ticket

清单里的票还没开。实现时按这个顺序。提议阶段不要改 `docs/TECH.md`。

### 1. 纯投影：授权和各类字节变成卡片文字

- 阻塞：无
- 交付：给定有没有授权，以及每一类的字节或缺失，得到卡片文字。未授权、或这一类缺失，文字是「—」。已授权且字节确实是 0 时仍是 0。不编一个大小。
- 测试接缝：纯投影。抓住缺数不会变成 0，也抓住未授权时六类都是「—」。放掉真正去扫磁盘、打开系统设置和移动废纸篓。投影不自己读盘。

### 2. Docker 文本和快照工具文本的纯解码

- 阻塞：无
- 交付：给定 Docker 引擎的文本，或快照工具的文本，得到字节或缺失。给不出字节数就是缺失，不是 0。
- 测试接缝：纯解码器。抓住坏掉的一行仍是缺失，不是 0。放掉真正去执行这些工具。

### 3. DashboardCore 只接受用户触发的扫描，删除只能进废纸篓

- 阻塞：第 1 张
- 交付：用户点了扫描，核心才收下那一份结果，并交给第 1 张的投影。采样交上来的结果被拒绝。删除动作只有移进废纸篓，永久删除进不来。没有对应目录可移的类别没有删除动作。
- 测试接缝：DashboardCore。抓住采样不会制造扫描结果，也抓住删除被限制成废纸篓。放掉文件是不是真的进了废纸篓，放掉系统里的完全磁盘访问开关，也不渲染界面。

### 4. 视图：按需引导、手动扫描、废纸篓

- 阻塞：第 3 张
- 交付：用户先打开这一视图，再点扫描。没有授权时只引导到系统设置，大小是「—」。已授权则扫描一次后停。能移的目录才进废纸篓。文案不写磁盘快满。磁盘速率页不出现这次授权。窗口的其余部分不被挡住。
- 测试接缝：WiringSourceTests。抓住源码里的冷静引导、手动扫描、「—」和废纸篓，也抓住速率页仍不申请完全磁盘访问。放掉 SwiftUI 是否真的跑起来，也放掉本机冒烟。锁的是简体中文源码，改词会失败。

### 5. 采纳之后更新 TECH.md 和冒烟清单

- 阻塞：第 4 张。还要等本 ADR 改为已采纳。在那之前不要把提议写进 `docs/TECH.md`。
- 交付：`docs/TECH.md` 和本机冒烟清单写明按需引导、手动扫描、缺数为「—」、删除只进废纸篓，以及速率页仍然不申请完全磁盘访问。
- 测试接缝：不新增接缝。行为仍由第 1 张的纯投影、第 2 张的纯解码器、第 3 张的 DashboardCore 和第 4 张的 WiringSourceTests 守住。文档不代替这些接缝。
