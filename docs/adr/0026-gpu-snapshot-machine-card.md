# ADR-0026：快照和本机页写入 GPU 使用率与占用内存

状态：已采纳（#231）。这是范围变化。原先产品范围把 GPU 使用率和 GPU 占用内存留在 GPU 页，不写进快照，也不放上本机页。本条只放开这两处。不改变 [ADR-0004](0004-gpu-accelerator-stats.md) 的读数来源。不改变 [ADR-0008](0008-gpu-history-keeps-recording.md) 的曲线，也不把核心数放进本机页、菜单栏、快照或进程表。不改变 [ADR-0009](0009-gpu-process-share.md)：GPU 占比仍不进菜单栏、快照、本机卡片或进程表。不改变 [ADR-0020](0020-gpu-power-energy-channel.md) 和 [ADR-0012](0012-energy-model-power-frequency.md)：GPU 功耗和 GPU 频率仍只在 GPU 页读，仍不进菜单栏、快照、进程表或本机历史。不改变 #219 的 IOReport 打开顺序。

## 背景

GPU 使用率和占用内存已经在每一页的主采样拍上发布。保存的快照和本机页原先故意不带这两个数，所以离开 GPU 页就看不到它们，保存的现场也没有。菜单栏要保持简洁。

## 决定

- 快照写入「GPU 使用率」和「GPU 占用内存」。取值是冻结时已经发布的 GPU 页读数，不新采样。缺失写「不可用」。真实 0 写成 `0.0%` 和「0 字节」，不写成「不可用」。不是有限数的使用率也写「不可用」。
- 不写入 GPU 功耗、GPU 频率、渲染器使用率、分块器使用率、核心数、GPU 占比、恢复次数或 GPU 时间。
- 隐去进程名、带用户名的路径、主机名和 IP 的规则不变。这两行 GPU 读数不是隐去项。
- 本机页增加一张 GPU 卡片，显示同一份已发布的使用率和占用内存。界面上缺失仍是「—」，真实 0 仍是 `0.0%` 和「0 字节」。点击调用 `selectPage(.gpu)`，打开 GPU 页。不在这张卡片上显示核心数、功耗、频率、渲染器或分块器。
- 菜单栏仍不显示 GPU 读数。进程表也不加。

## 后果

- 预览、HTML 和 Markdown 多这两行。
- 本机页多一张可点的卡片。新代码在 `MachineOverviewSection+GPU.swift`，因为本机页主文件已经 500 行。
- 不要把功耗、频率、渲染器、分块器或核心数补进快照或这张卡片，也不要在菜单栏加 GPU。

## 不考虑

- 快照里用「—」而不是「不可用」：快照全文的缺失记号已经是「不可用」。
- 本机卡片显示「不可用」：本机页其它读数用「—」。
- 把 GPU 占比或功耗放进这张卡片，或为了快照再读一次加速器。
