# Pulse 一期需求文档

> 好看的 Mac 内存诊断器：外表像活动监视器，任务按诊断走。一期单页打透内存，供设计与研发对齐验收。

**已锁定**：仓库 [qqzhangyanhua/pulse](https://github.com/qqzhangyanhua/pulse)（private）。暂名 Pulse，正式品牌待定。栈：SwiftUI 原生、公证直装。不做 Electron。

来源：[Pulse 一期需求文档（Canvas）](https://cursor.com/canvas/store-f808b75c-0f2a-4a23-b931-936096bdb525/eab315e2-3e6b-4711-9d5d-ec04e1951f1b)

## 问题与用户

macOS 自带活动监视器信息密度高、不易一眼判断「谁在吃内存、压力是否偏高」。用户需要一个好看且好用的本地工具，在卡顿或内存吃紧时快速定位并处置进程。

| 项 | 内容 |
| --- | --- |
| 主用户 | 日常 Mac 用户 + 开发者（同一界面） |
| 情境 | 机器变慢、内存压力升高、怀疑某 App 占用异常 |
| 要完成 | 看清总览 → 找到嫌疑进程 → 安全退出/强制退出 |
| 平台 | 仅 macOS 桌面端 |

## 定位与成功标准

对外一句话：好看的 Mac 内存诊断器。策略是 A 壳 + B 核——视觉克制原生（像好看的活动监视器），默认信息流与动作按诊断排。

- 默认进入内存页；进程表默认按内存占用降序
- 压力状态优先暴露（正常 / 偏高），文案冷静，无吓人告警
- **成功标准**：用户能在约 30 秒内定位吃内存的进程并安全退出

## 一期范围（Must）

| 模块 | 要求 |
| --- | --- |
| 系统总览 | 用量大数、内存分类条（App / Wired / Compressed / Cached）、压力状态与压力曲线 |
| 进程表 | 名称、CPU%、内存、线程；默认按内存降序；支持名称过滤 |
| 进程详情侧栏 | 图标与名称；内存/CPU 大数；内存曲线为主、CPU 曲线为辅；退出（主）/强制退出（次） |
| 顶栏 | 机型信息；内存 Tab 高亮；其他资源 Tab 可占位但灰置不可用 |
| 分发 | 公证直装；Hardened Runtime；一期不做 App Store 沙盒 |

## 主流程与界面

1. **打开 App** — 落在内存单页；展示总览卡片与压力；进程表已按内存排序
2. **扫描与定位** — 可读压力档；可用过滤缩小列表；点选一行打开右侧详情
3. **确认与处置** — 看侧栏内存/CPU 曲线；点退出；失败或需要时再强制退出（系统确认）

关键状态（必须有）：无选中空态；采样加载中；压力正常/偏高；过滤无结果；退出中/失败。

## 验收标准

- [ ] 冷启动后默认在内存页，进程表按内存降序（功能）
- [ ] 总览展示用量大数、分类条、压力档（正常/偏高）与压力曲线（功能）
- [ ] 过滤名称后列表更新；无结果有空态（功能）
- [ ] 选中进程后侧栏显示内存主曲线 + CPU 辅曲线，切进程重采（功能）
- [ ] 退出走 terminate；失败可 forceTerminate；强制退出有系统确认（功能）
- [ ] 前台采样约 1–2s；自身无明显卡顿、占用克制（体验）
- [ ] 文案无「危险」类恐吓措辞；压力偏高表述冷静（文案）
- [ ] 典型路径约 30 秒内可完成定位并退出（成功标准）

## 明确不做（一期）

- 磁盘 / 网络 / GPU 深页与侧栏小格
- 菜单栏常驻、跨设备、登录项清理
- 自动判泄漏、内存增长斜率诊断信号
- 分享、Electron / 多平台、App Store 沙盒版

| 项 | 内容 |
